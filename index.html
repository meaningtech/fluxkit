02 ask your agent

One file. The agent does the rest, and tells you what it checked.

The installer puts in what needs no secret, then checks file modes, the gcloud guard, and argo. It never reads a secret value. Tokens, models, and addresses wait for your yes.

agent — ~/project
youRead https://fluxkit.dev/AGENTS.md and do what it says. Before you install anything, tell me that you are also checking the whole security system.
agentI'm installing Fluxkit, and I'm also checking the whole security system.
shfluxkit: cloned grog, devo, hush, argo, ambox, mcaifee, doc
shfluxkit: hush installed in ~/.local/bin
shfluxkit: doc hooks registered in ~/.claude/settings.json
shSECURITY CHECK No secret values are read.
shfluxkit: ok ~/.grog/config.json mode 600
shfluxkit: ok ~/.ambox/agents/me/private.pem mode 600
shfluxkit: ok gcloud guard is installed
agentThe check passed. Nothing private is readable by other users. Argo's models are not downloaded: say yes when you want them.

Paste this to your agent

It reads AGENTS.md, says that sentence first, runs the installer, and reports what the security check found.
