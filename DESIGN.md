# Fluxkit landing

Black page. Terminal type. One white mark.

The mark is the conduit: three strokes meeting at a point. The stem points up. The two arms point down. That is the usual figure turned 180 degrees. It is white, with a short white bloom, and it is the only picture on the page.

## Type

Monospace. No display font, no color rows, no case, no wood.

The name of the page is `fluxkit`, set like a prompt. Under it, eight lines. Each line is a name and one sentence. The names are links. The sentences have the same weight.

Devo is a public repository. The page does not call it private.

## Ask the agent

One line: `ask your agent`. Two controls, each an icon and a word.

Copy writes exactly:

```text
Read https://meaningtech.github.io/fluxkit/AGENTS.md and do what it says.
Before you install anything, tell me that you are also checking the whole security system.
```

The word changes to `copied` for two seconds. If the clipboard refuses, it changes to `copy failed`.

Open is a link to `AGENTS.md` with `target="_blank"` and `rel="noopener noreferrer"`.

## Viewports

The column is at most 40rem, centered, with the same stack at every width. At 1440, 1280, 1024, 768, and 390 the page does not scroll sideways. Descriptions wrap. The mark stays under 200 pixels wide.

## Open Graph

`og.png` is 1200×630, black. The same mark, stem up, in white. Under it, the line “Where we're going, we don't need roads.” and the attribution Back to the Future. The page points `og:image` and `twitter:image` at `https://meaningtech.github.io/fluxkit/og.png`.

The favicon is the same mark on black: `favicon.svg` for current browsers, `favicon.ico` at 16, 32, and 48, and `apple-touch-icon.png` at 180.
